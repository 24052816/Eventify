
# Eventify - Event Management Website

## About the Project

Eventify is a modern and responsive event management website developed using HTML5, CSS3 and JavaScript.

It allows users to explore upcoming events, search for events, filter events by category and register for their favourite events.

## Features

- Attractive and modern homepage
- Responsive design for mobile, tablet and desktop
- Upcoming events displayed using event cards
- Search events by name and venue
- Filter events by category
- Event registration form
- JavaScript form validation
- Registration confirmation message
- Dark mode and light mode
- Local Storage to save registration details
- Smooth transitions and hover effects

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Explore the Eventify website in your browser.

## Registration System

The website collects the participant's name, email address and phone number.

JavaScript validates the submitted information and saves successful registrations in the browser's Local Storage.

Note: This project uses browser-based storage and does not have a backend database.
